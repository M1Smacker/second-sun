**Concern written before results (so it cannot be tuned away later):** the stack score is sum(min(SNR, 7)) / sqrt(n), and the floor is max(7, highest null best-stack over ALL untouched hosts + 1). A three-member set can score at most 7 x sqrt(3) = 12.1, four 14.0, five 15.7. If any one null host gives a capped three-member set (X2 found chance strong pairs common), the floor reaches 13.1 and no three-member set can ever pass; part A (promotion) uses the same floor. So a "fails" may come from a floor that is unreachable by construction, not from the physics. When the result lands I will report the floor next to these ceilings, and say plainly if the test could not pass by design. No change to the design is made or asked for now.
