The chosen implementation retains this median-subtraction approach. [Armstrong et al. 2014](https://arxiv.org/html/1404.5617v2).

For each product of each design star-sector, preserve quality loading, safe windows and the existing eclipse mask. Use the pre-eclipse-mask first retained timestamp as phase origin, catalogue period, and elapsed span. If span is below three periods, return the original flux exactly. Otherwise start with min(200, max(20, floor(period / 0.1 day))) equal phase bins. Halve the number of bins until every occupied bin contains cadences from at least three distinct cycle indices. Empty bins have no evaluated points. If even one bin lacks three cycles, skip. Use each occupied bin's median as its piecewise-constant model. Return flux minus that model plus the global median. Subtraction retains additive flux units and commutes with flux inversion. Its fitted model can absorb planted signals. The model is estimated afresh with injections already present.
