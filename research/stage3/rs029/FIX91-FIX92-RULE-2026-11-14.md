# FIX 91 and FIX 92 bench pricing (Claude Opus 5.5 high, written 14 Nov 2026, about 9:06 pm Kuwait, BEFORE any run)

Same harness as RS-024 and RS-029 (`rs029_fix9192.py`), baseline OAE (the adopted fairness fix). Options:
- **OAE91m (FIX 91, mirror):** the opposite-sign coincidence flag is applied to BOTH arms: an upside-down event is flagged when a real event of the same light curve and product sits within 0.3 d (FLIP_D, frozen value), exactly as a real event is flagged by an upside-down one today.
- **OAE91d (FIX 91, drop):** the flag is switched off in both arms.
- **OAE92 (FIX 92):** a second product counts as a judge only if it could have seen the event: expected SNR there = event SNR x (that product's SNR / this product's SNR for the same test dip in the same star-sector; the 8 h injection stored in every group file). If no other product reaches an expected SNR of 5, the event is treated as having no second product (tier 1B), never as disagreement (tier 3). E_MIN = 5 is fixed now (a seen SNR under 3 against an expected 5 is a 2-sigma shortfall under unit noise); 4 and 6 are NOT run, so the number cannot be picked after the fact. Limits: events store only the best second SNR, so with 3 or more products the rule only removes tier 3 when NO other product could see the event (conservative); the ratio is measured at 8 h for one depth; SAP twins use their parent product's ratio.

**Pass rules (Tree rule 1, amended):**
1. FIX 91 is a fairness fix (the flag today hits dips only). OAE91m or OAE91d is adopted if the paired control passes in all five bins, P falls by at most 0.5 points against OAE, and the tier-1 upside-down background is not higher than OAE's. If both pass, mirror wins (smaller change from the frozen idea: keep the flag, make it fair).
2. FIX 92 is a planet fix: adopted only if P rises against OAE, the upside-down background is not higher than OAE's, and the paired control passes in all five bins.
3. Bench numbers on the design stars are one key (Claude). Codex's T156 bench is the second key before any freeze.
