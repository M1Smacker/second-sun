**Plain:** A run now takes its star set and options from its own settings file, and stops loudly if any input is missing.
**Why it matters:** A leftover shell setting or an empty data folder could otherwise send the one-shot G1 run to the wrong stars without anyone noticing.
**Explanation:** The old runner read two shell variables and wrote "missing" into its fingerprint when a file was absent. The new helper refuses both cases before any light is read.
**Technical:** apply() sets SS_SET and VESPER_OPTS from JSON and refuses conflicting shell values; require() checks data folder, manifest, best-product table, targets and at least one light-curve file per star. 8 of 8 tests pass; mutations of the conflict and file checks go red. Not in the frozen hash list. G1 runner imports it.
