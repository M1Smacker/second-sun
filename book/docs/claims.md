# Claims register

!!! plain "In plain words"
    Ahmed, every fact the book relies on lives here once, with how sure we are and where it came from. Pages show a small label next to a fact; tap it and you land on its row here.

## How to read the labels

The shape carries the meaning, not the colour. <a class="ss-chip ss-chip--verified" href="#how-to-read-the-labels">VERIFIED</a> (solid outline) means we read the original source or measured it ourselves. <a class="ss-chip ss-chip--likely" href="#how-to-read-the-labels">LIKELY</a> (dashed) means a summary or secondary source. <a class="ss-chip ss-chip--unverified" href="#how-to-read-the-labels">UNVERIFIED</a> (dotted) means memory or one weak source: test before relying on it.
