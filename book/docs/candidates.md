# Candidates

!!! plain "In plain words"
    A **[candidate](glossary.md#candidate)** is a dip that passed our first checks. It is *not* a planet. Each one gets an ID (SS-0001, SS-0002, ...) and, once it survives vetting, a nickname. It needs **two keys** before it goes anywhere: my analysis, and your own check.
