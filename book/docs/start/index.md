# Start here

<p class="ss-meta">Start here · about 2 min</p>

!!! plain "In plain words"
    This book is our project diary, and it teaches as it goes. All you have to do is read. The hands-on labs are optional side trips.

## Three steps

1. [The story so far](story-so-far.md) (12 minutes): what happened, in order, and where we stand.
2. [How to read this book](how-to-read.md) (5 minutes): the labels, the readiness bar and how a chapter works.
3. Pick a path, below.

## Two ways through

Both ways use the same pages. You can switch at the bottom of any chapter.

**The journey.** The ideas in the order the project needed them, with a line saying what happened at each stop. [Open the journey](journey.md), or go straight to its first stop, [Chapter 4: two suns](../book/04-two-suns.md).

**By topic.** The same chapters in teaching order, Part 1 to Part 6, the way a textbook would go. Start at [Chapter 1: stars, names and missions](../book/01-stars-names-missions.md), or open [Part 1](../parts/part1/index.md).

## Optional

- **Try it yourself.** At the end of each Part there is a page of hands-on labs for your PC. Each one shows the real output first, so you can follow without running anything.
- **Check yourself.** Each Part has one review page of questions. Nothing is scored or saved.
- **Field notes.** One short lesson per working day, under the [Hunt tab](../field-notes/index.md).
