# Start here

<p class="ss-meta">Start here · about 2 min</p>

!!! plain "In plain words"
    This book is our project diary, and it teaches as it goes. There is one path through it, the learning track. It starts with the first thing you need to know and builds up one level at a time. The hands-on labs are optional side trips.

## Three steps

1. [The story so far](story-so-far.md) (12 minutes): what happened, in order, and where we stand.
2. [How to read this book](how-to-read.md) (5 minutes): the labels, the readiness bar and how a chapter works.
3. [The learning track](../learn/index.md#l0): start at Level 0.

## One path

The learning track has seven levels and a last step. Each level says what to read, in order, and ends with three questions. When you can answer them, you move up.

The chapters are numbered by topic and the numbers never change, so the track reads them in a different order: Chapters 1, 2 and 3 first, then 7 and 8, then 4, 5 and 6. That is on purpose. You learn to read and measure a light curve before you meet the orbits that make our dips hard to predict.

## If you would rather browse

- **How the project unfolded.** [The same chapters in the order the project met them](journey.md). It is a story, not a reading order.

## Optional

- **Try it yourself.** At the end of each Part there is a page of hands-on labs for your PC. Each one shows the real output first, so you can follow without running anything.
- **Check yourself.** Each level on the learning track ends with three questions, and each Part has one review page. Nothing is scored or saved.
- **Field notes.** One short lesson per working day, under the [Hunt tab](../field-notes/index.md).
