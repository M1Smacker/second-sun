## The idea behind it

**Idea (measure the claim):** advice is a claim. Some claims have a number that can contradict them, such as a contrast ratio, a character count or a list of characters in a file. For those, checking with a tool beats reading, because a tool can say no. A **contrast ratio** compares the brightness of text and its background; 7 to 1 means the lighter is seven times brighter once a small allowance is added to both. Black on white is 21 to 1. A **character map** is the list of characters a font file can draw; if a character is missing, the device quietly borrows one from another font.

**Idea (an honest label on every claim):** the font report marked some facts as verified and some as estimates, and the estimates were true estimates. That is the standard we hold ourselves to: say which is which.

**Idea (decide before you build):** the learning-path review ended with three questions for you, not with code. Changing the order of a book changes how you learn, and that is your call.

**Idea (make new code rebuild an old answer):** before trusting new code, ask it to reproduce a result you already trust. Our Stage 3 preparation rebuilt the published Stage 2 numbers exactly (36 real events cut to 12, 7, 7, 4, 4, 4 and 1), and a re-run of the five known stars gave identical events. If either had differed, the new code would have been wrong, not the old result. This is called a **regression test**.

**Idea (a flag is not a deletion):** a rule such as "this event sits near a known eclipse" marks the event and moves it to a lower tier. It never throws the event away, because a real planet can cross at an awkward moment.

**Idea (count the kind of mistake, not only the score):** "93% right" hides that a missed planet, a false alarm and a mislabelled glitch cost the hunt different things. A miss loses a candidate, a false alarm wastes a check, and a glitch taken for a dip is the one that could fool us. Sort the misses by kind before judging anyone, a person or a program.

**Idea (prove a test can say no):** a test that has never failed has not shown it works. After the new layout test passed, we widened the reading column in a scratch copy and the test named every page it broke. Only then did we trust its pass.

**Idea (let the interval choose the word):** a rate is an estimate, and the 95% confidence interval is the span of true rates it fits. If the whole span is on the good side of a target, say so. If the span crosses the target, say that too. With 32 quiet curves even zero false alarms cannot show the true rate is under 10%, because the interval still reaches 10.7%. About 35 curves with none are needed. More curves, not a kinder sentence, are what move a result.

**Idea (size a picture by its shape, not by the window):** a plot's height is set by its **aspect ratio**, the height divided by the width. A share of the window makes the same plot tall on one screen and flat on another, so the dips change shape. Fix the ratio, then add a floor and a ceiling so it is never too small to read or too big to see whole.

**Idea (reserve the space before you need it):** if a button appears only after an answer, leave its slot empty from the start. Then the page does not jump under your finger when it arrives.

**Idea (one fact, one place):** a results page is clear when each number appears once, next to the line it is judged against. Repeating a fact in three lists does not make it safer, it only hides the one number you came for.

## Questions

??? quiz "1. A font file lacks the character σ. What does your phone do when a page asks for it?"
    It quietly draws σ from another font on the phone. Nothing breaks, but the letter can look slightly different from the text around it.

??? quiz "2. Why was it better to calculate the contrast of the brass colour than to look at it?"
    A calculation gives a number that can contradict the claim (2.9 against a rule of 7). Looking only gives an impression, and our eyes forgive low contrast on a bright screen.

??? quiz "3. Why did we re-run the five known stars through the new code before searching the rest?"
    To prove the new code returns the same events as Stage 2. Then any difference in Stage 3 comes from the new rules, not from a slip in the code.

??? quiz "4. Why is a single score such as 93% not enough to judge how well someone spots dips?"
    Because the wrong answers differ in kind. Missing a faint dip, calling a quiet curve a dip and mistaking a jump for a dip each cost the hunt something different, so the misses must be sorted by kind first.
