# Progress

A quiet record of where you are, Ahmed. It updates when we commit a change to the `progress/` files, so the history is also in git.

## Mission readiness

This is how complete and how well built **our plan** is, from 0 to 100. It is **not** the chance of finding a planet: a careful search that finds nothing is still a finished plan, so candidates are counted separately. Every point needs proof (a fact in the claims register or a file in the repo), the program counts some items by itself (for example, how many of the 549 stars have been searched), and the number is allowed to go **down** if a result is overturned. Each change to the number is logged below with its reason, and the book will not build if a point has no proof or a change is not logged.
